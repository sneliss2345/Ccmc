# Орбита

Аркада в одно касание для Android и браузера. Комета кружит вокруг планеты; касание экрана срывает её с орбиты по касательной. Нужно долететь до кольца следующей планеты и не улететь в пустоту.

![Иконка](web/icons/icon-192.png)

## Как играть

- **Касание** — сорваться с орбиты. Пунктир впереди кометы показывает направление вылета.
- **Попадание прямо в планету** даёт «В центр!» и растущую серию: каждое точное попадание подряд приносит больше очков.
- **Прыжок через планету** засчитывает все пропущенные планеты.
- **Звёзды** копятся между забегами. За них открываются новые хвосты комет и можно один раз продолжить забег после крушения.
- Каждые 12 планет комета попадает в новый сектор: Пояс Койпера, Туманность Ориона (M42), Крабовидная (M1), Кольцо (M57), Столпы Творения (M16), Кошачий Глаз (NGC 6543), Тарантул (NGC 2070) и Центр Галактики.

Опасности появляются постепенно:

| Опасность | С какой планеты | Что делать |
| --- | --- | --- |
| Луны на внешней орбите | 5 | Проскочить между ними при взлёте и посадке |
| Дрейфующие планеты | 9 | Брать упреждение |
| Красные нестабильные планеты | 14 | Улететь, пока не кончился отсчёт |
| Чёрные дыры | 16 | Не подлетать к центру: гравитация искривляет полёт |

Бонусы: **щит** спасает от одного крушения, **магнит** 9 секунд притягивает звёзды.

## Установка на Android

Каждый пуш в `web/` или `android/` собирает APK через GitHub Actions (`.github/workflows/android.yml`) и публикует его в **Releases** репозитория как `orbita-1.0.N.apk`.

1. Открой страницу Releases с телефона и скачай последний `.apk`.
2. Открой файл и разреши установку из этого источника.

Сборку можно запустить и вручную: Actions → Android APK → Run workflow.

## Запуск в браузере

Игра целиком лежит в одном файле `web/index.html` без зависимостей. Для локального запуска:

```sh
cd web && python3 -m http.server 8000
```

и открыть `http://localhost:8000`. Если раздавать папку `web/` по HTTPS (например, через GitHub Pages), игру можно установить на домашний экран как приложение: есть манифест и офлайн-кэш (`sw.js`).

## Структура

```
web/            игра: index.html, манифест PWA, service worker, иконки
android/        WebView-обёртка (Java, без зависимостей); ассеты берутся из web/
.github/        сборка APK и публикация релиза
```

Локальная сборка APK (нужен Android SDK): `cd android && ./gradlew assembleDebug`.
